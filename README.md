# MARGIN

Most planning apps only track tasks and deadlines — they don't account for whether you actually have the time, sleep, or energy to get through them. MARGIN looks at your real weekly capacity instead: sleep, commute, existing responsibilities, and recovery time,so what you plan is what you can actually do.

## Try it

https://favour187.github.io/MARGIN/

## How it's built

MARGIN is offline-first,once it loads once it can keep working without internet, no API calls is made. Capacity calculations and the Reset Engine run locally in the browser, with no server dependency for core functionality.

## Privacy

the website was made in such a way that data stays on your device where possible. No account is required to use the core features.
